BELIEVER'S INTERNATIONAL SCHOOL — STATIC WEBSITE
==================================================

Open index.html in a browser to preview the site.

FILES
-----
index.html       Main page
styles.css      Complete green visual system + responsive layout
script.js       Navigation, scroll effects, curriculum tabs, gallery, video embeds
site-config.js  Add YouTube/Vimeo links here
assets/images/  Images supplied for the website

VIDEO LINKS
-----------
Open site-config.js and paste your YouTube or Vimeo URL into the `url` field.
The placeholder is automatically replaced with the embedded video.

IMPORTANT CONTENT REVIEW
------------------------
The curriculum, fees, 2027 admission dates, required documents, phone numbers,
website address and most school features were transcribed from the supplied
brochures. Before public launch, please confirm spellings, phone ownership,
exact campus address, and that all fee/date information is still current.

DESIGN
------
This revision intentionally uses ONE green visual language across the full site:
dark pine / forest green / emerald / mint / ivory. There is no separate blue UI
theme. Blue may still appear naturally inside the supplied school logo or brochure images.

DEPLOYMENT
----------
Upload all files and folders together to public_html, Netlify, Vercel,
Cloudflare Pages, GitHub Pages, or any static web host.
